# Security policy

Do not disclose suspected vulnerabilities in a public issue. Report them privately through [GitHub's private vulnerability reporting](https://github.com/benjamin-small/3d-print-sketches/security/advisories/new). Include reproduction steps, affected versions, and potential impact.

The maintainer will acknowledge a complete report as soon as practical and coordinate remediation and disclosure with the reporter.

Support covers the latest source on `main` and the current revision 7 print
pack. Older design revisions are not maintained; reproduce a report against
the latest version when possible. This project has no hosted service, API,
credentials, or printer control. Security fixes to the Python builder and its
dependencies receive priority over support for superseded exports.
